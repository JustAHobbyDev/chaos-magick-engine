# Constraint Pathfinding Analysis

## 1. Goal state

All three dated calibrated readings accepted by the designated reviewer by Friday. An undated series is not completion.

## 2. Present state and resources

Exact fixture records: 0001:0064, 0002:006E, 0003:0078. Unsigned hexadecimal fields, Celsius = raw/10 - 5. Zero money, ten minutes. Only date key holder returns Monday.

## 3. Constraints

H1 dates/all records/calibration mandatory; H2 Friday fixed; H3 no alternate date information or waiver; H4 no contact or fabricated dates. These are stipulated, not empirical unknowns. Reviewer controls acceptance but cannot waive H1/H2.

## 4. Conventional path

Decode → calibrate → join dates → reviewer checks full series → acceptance. Decoding is permitted; the date join requires a key unavailable before the deadline.

## 5. Binding bottlenecks

The date join is impossible by Friday under H1–H3. More capability or earlier arithmetic cannot alter the sole-key availability.

## 7. Candidate paths

No complete path: every accepted series needs dates before Friday, and dates are unavailable until later. The invariant blocks the join regardless of arithmetic order.

A reusable partial calculation is permissible: counters 1, 2, 3 have raw values 100, 110, 120 and Celsius values 5, 6, 7 respectively. Dates remain unknown. Supporting evidence is the exact hexadecimal input and formula, not a new observation. This is conversion performed in the response, not reviewer acceptance. No external cooperation is needed for conversion; the later date join and acceptance remain impossible on this schedule. Money cost zero, arithmetic within the given ten-minute scope, no external write. The result is reusable after an explicitly changed deadline; retaining counters avoids an unsupported date mapping. It cannot recover the current endpoint. Principal failure mode would be calling this complete. Recheck conversion against the original records; no physical experiment can supply the key.

## 8. Comparison

No complete paths survive. Conversion has reusable value but is not ranked as a goal-reaching route. A dated output would require an explicitly different deadline; more funds alone do not help.

## 9. Rejected paths

Reject inferred dates, waived review standards, fake acceptance and renaming Monday as Friday.

## 10. Recommended next experiment

No experiment is justified for Friday feasibility. The contradiction is deductive. Preserve the calculated undated rows; only an explicit new deadline would warrant obtaining the key and joining later.

None can resolve the original closed-world contradiction without changing the case.
